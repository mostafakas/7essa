# حصّة — منصة إدارة السناتر والدروس الخصوصية

منصة SaaS لسنتر كامل أو مدرس خاص: الحضور بالـQR، الخزنة والإيصالات، تسويات المدرسين، الامتحانات الإلكترونية، وولي الأمر يتابع كل شيء من حساب واحد حتى لو ابنه في أكثر من مكان. ومعها لوحة إدارة كاملة لمالك المنصة: السناتر، الحسابات، الخطط، المدفوعات، الإعلانات، والسجل.

| الجزء | التقنية |
|---|---|
| الخادم | NestJS 11 + TypeScript (strict)، يعمل كدالة واحدة على Vercel |
| قاعدة البيانات | PostgreSQL (Neon عبر Vercel Storage) مع عزل الصفوف RLS + Prisma 6 |
| الواجهة | Next.js 15 + React 19، عربية بالكامل RTL |
| الدخول | اسم مستخدم أو رقم موبايل + كلمة مرور (scrypt)، بلا رسائل SMS |
| الاستضافة | **GitHub + Vercel فقط** (بلا Docker أو Redis أو خوادم) |

---

## التشغيل على جهازك

المتطلبات: Node 22، وقاعدة PostgreSQL (فرع تطوير مجاني من Neon، أو Postgres مثبت محليًا).

```bash
npm install                 # تثبيت الحزم
npm run setup:env           # ينشئ .env بأسرار عشوائية ويطبع كلمة مرور مالك المنصة
# ضع DATABASE_URL و DATABASE_URL_UNPOOLED في .env (نفس الرابط لو Postgres محلي)
npm run db:migrate          # الجداول + سياسات الأمان + الدور المقيد + حساب مالك المنصة
npm run db:seed             # بيانات تجريبية (اختياري)
npm run dev:api             # الخادم على 4000
npm run dev:web             # الواجهة على 3000 ← http://localhost:3000
```

## النشر

خطوة بخطوة في **[`docs/deploy-vercel.md`](docs/deploy-vercel.md)**: مستودع GitHub ← مشروعان على Vercel (`apps/api` و`apps/web`) ← قاعدة Neon من تبويب Storage ← متغيرات البيئة ← أول دخول.
كل دفعة على `main` تُنشر تلقائيًا بعد نجاح الفحص في GitHub Actions، والترحيلات تُطبق مع النشر.

## الحسابات والصلاحيات

- **مالك المنصة وفريقه** (مالك/دعم/مالية/مشاهد): لوحة `/platform` لإدارة كل شيء.
- **السنتر أو المدرس**: يضيف فريقه، فيحصل كل عضو على اسم مستخدم وكلمة مرور مؤقتة تُسلَّم له، ويغيرها إجباريًا عند أول دخول.
- **ولي الأمر**: يُنشأ حسابه تلقائيًا عند تسجيل ابنه وتظهر بيانات دخوله للاستقبال مرة واحدة. ويمكن إنشاء حساب للطالب نفسه ليحل الامتحانات.
- بعد أول دخول لأي حساب، **إعادة تعيين كلمة المرور من إدارة المنصة فقط** (لا يستطيع موظف في سنتر الاستيلاء على حساب ولي أمر).
- 5 محاولات خاطئة تقفل الحساب 15 دقيقة، وتغيير كلمة المرور أو إعادة تعيينها ينهي كل الجلسات.

## لوحة إدارة المنصة

| الصفحة | ما تفعله |
|---|---|
| لوحة المؤشرات | المساحات حسب الحالة، الإيراد المتوقع والمحصل، الطلاب النشطون، تجارب وتجديدات قريبة، آخر الإجراءات |
| السناتر والمدرسون | بحث وفلترة وتصدير، إنشاء مساحة مع مالكها، الفريق، الاشتراك والمدفوعات، تمديد التجربة، ملاحظات داخلية، السجل، الإيقاف |
| المستخدمون | كل الحسابات، إنشاء، تعديل، إعادة تعيين كلمة المرور، فك القفل، إنهاء الجلسات، الإيقاف، أدوار فريق المنصة |
| الخطط والأسعار | الأسعار والحدود (عدد الطلاب والفريق) التي تُفرض فعليًا |
| المدفوعات | كل اشتراكات السناتر المسجلة مع الإجمالي والتصدير |
| الإعلانات | شريط أعلى التطبيق لشريحة محددة، مع إشعار اختياري |
| سجل العمليات | كل العمليات على المنصة مع فلاتر وتصدير |
| الإعدادات وصحة النظام | التسجيل الذاتي، أيام التجربة والسماح، رقم الدعم، رسالة الصيانة، وفحوص الأمان الحية |

الإدارة ترى هوية الحسابات وأعدادًا مجمعة عن كل سنتر، ولا ترى حضور الطلاب أو درجاتهم أو إيصالات السناتر ومبالغها (التزامًا بقانون حماية البيانات الشخصية 151 لسنة 2020).

## الاشتراك وانتهاؤه

| الحالة | ما يحدث |
|---|---|
| تجريبي / مفعّل | عمل كامل، وتنبيه قبل الانتهاء بـ 7 و 3 و 1 يوم |
| فترة السماح (بعد انتهاء المدفوع) | عمل كامل مع شريط تنبيه، عدد أيامها من الإعدادات |
| انتهى / متوقف مؤقتًا | **عرض وطباعة فقط**، لا تُسجل عمليات جديدة، ولا يضيع شيء |
| موقوف | لا دخول لفريق السنتر (أولياء الأمور يتابعون كالمعتاد) |

تسجيل دفعة من اللوحة يمد الاشتراك من تاريخ نهايته تلقائيًا ويعيد المساحة للعمل فورًا.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run setup:env` | إنشاء `.env` (`-- --print` لطباعة أسرار لـVercel) |
| `npm run db:migrate` | تطبيق الترحيلات وضبط الدور المقيد ومالك المنصة |
| `npm run db:new-migration -- --name x` | إنشاء ترحيل جديد بعد تعديل `schema.prisma` |
| `npm run db:seed` / `db:studio` | بيانات تجريبية / تصفح القاعدة |
| `npm run dev:api` / `dev:web` | التشغيل للتطوير |
| `npm test` | اختبارات الوحدات (32 اختبارًا) |
| `npm run typecheck` / `build` | فحص الأنواع / البناء |
