# خارطة الطريق

## ما هو جاهز في هذا الإصدار

- بوابة السنتر والمدرس الخاص بسبعة أدوار وصلاحيات مفروضة في الخادم.
- الحضور بالكارنيه والـQR المتغير والكود، بقارئ أو كاميرا، مع العمل دون اتصال.
- الخزنة: ورديات، إيصالات مرقمة، خصومات محدودة، إلغاء بمبدأ الشخصين، مصروفات، متأخرات، تقرير شهري.
- محرك التسويات بأربع صيغ تعاقد مع السلف والترحيل ودورة التأكيد والاعتماد والصرف.
- الامتحانات: بنك أسئلة، استيراد نصي، بناء بالمواصفات، حل إلكتروني، نتائج ورقية، تحليل الأسئلة.
- بوابة الأسرة: هوية موحدة، جدول مجمع، موافقة، مدفوعات، درجات، امتحانات، وحساب مستقل للطالب.
- **الدخول باسم مستخدم وكلمة مرور** مع كلمات مؤقتة تُطبع وتغيير إجباري وقفل ضد التخمين.
- **لوحة إدارة المنصة**: المؤشرات، السناتر، المستخدمون، الخطط، المدفوعات، الإعلانات، السجل، الإعدادات وصحة النظام، بأربعة أدوار لفريق الإدارة.
- **الاشتراكات**: تجربة، فترة سماح، وضع العرض فقط عند الانتهاء، حدود الخطط، تذكيرات يومية تلقائية.
- **تصدير Excel** للطلاب والمتأخرات والمساحات والمستخدمين والمدفوعات والسجل.
- **النشر على GitHub + Vercel فقط** مع فحص تلقائي للترحيلات في CI.

## المرحلة التالية (قبل الإطلاق التجاري)

1. **الدفع الإلكتروني للاشتراكات** (Paymob أو Fawry): تجديد ذاتي من صفحة الإعدادات بدل التسجيل اليدوي، مع إيصال تلقائي.
2. **واتساب للإشعارات** (WhatsApp Cloud API) كقناة مدفوعة: وصول الطالب، الإيصال، التذكير بالمتأخرات. ويمكن استخدامه لاحقًا لاستعادة كلمة المرور ذاتيًا.
3. **تطبيق الموبايل** (React Native) لولي الأمر والطالب بإشعارات فورية، وتطبيق خفيف للاستقبال بقارئ الكاميرا.
4. **اختبارات تكامل لسياسات RLS** على قاعدة حقيقية في CI (محاولات وصول بين مساحات العمل وبين أولياء الأمور).
5. **المراقبة**: تنبيهات أخطاء (Sentry أو ما يماثله) ولوحة لمحاولات الدخول الفاشلة.
6. **المصادقة الثنائية** لحسابات فريق المنصة وملاك السناتر.

## لاحقًا

- الدفع الإلكتروني لأولياء الأمور (محافظ، فوري) مع إيصال تلقائي.
- قراءة البابل شيت بالكاميرا وإدخالها عبر مسار النتائج الورقية الموجود.
- أسئلة مقالية مع تصحيح يدوي، وصور في الأسئلة.
- محتوى مسجل (فيديو) بحماية ومتابعة مشاهدة.
- تقارير مقارنة بين الفروع لسلاسل السناتر.
- تصدير PDF للتقارير والكشوف.
