# خارطة الطريق

## ما هو جاهز في هذا الإصدار (MVP)

- بوابة السنتر والمدرس الخاص بسبعة أدوار وصلاحيات مفروضة في الخادم.
- الحضور بالكارنيه والـQR المتغير والكود، بقارئ أو كاميرا، مع العمل دون اتصال.
- الخزنة: ورديات، إيصالات مرقمة، خصومات محدودة، إلغاء بمبدأ الشخصين، مصروفات، متأخرات، تقرير شهري.
- محرك التسويات بأربع صيغ تعاقد مع السلف والترحيل ودورة التأكيد والاعتماد والصرف.
- الامتحانات: بنك أسئلة، استيراد نصي، بناء بالمواصفات، حل إلكتروني، نتائج ورقية، تحليل الأسئلة.
- بوابة الأسرة: هوية موحدة، جدول مجمع، موافقة، مدفوعات، درجات، امتحانات.
- لوحة مالك المنصة بأرقام مجمعة.

## المرحلة التالية (قبل الإطلاق التجاري)

1. **الرسائل**: مزود SMS مصري أو WhatsApp Cloud API للرموز، ثم الإشعارات عبر واتساب كقناة مدفوعة.
2. **تطبيق الموبايل** (React Native) لولي الأمر والطالب بإشعارات FCM، وتطبيق خفيف للاستقبال بقارئ الكاميرا.
3. **الاشتراكات والدفع**: فوترة الخطط (Paymob أو Fawry)، وتذكير انتهاء التجربة، وإيقاف تلقائي بعد المهلة.
4. **الدفع الإلكتروني لأولياء الأمور** (محافظ، فوري) مع إيصال تلقائي.
5. **اختبارات تكامل** على قاعدة بيانات حقيقية لسياسات RLS (محاولات وصول بين مساحات العمل) في CI.
6. **المراقبة**: Sentry أو ما يماثله، وسجلات مركزية، ولوحة صحة الطوابير.

## لاحقًا

- قراءة البابل شيت بالكاميرا وإدخالها عبر مسار النتائج الورقية الموجود.
- أسئلة مقالية مع تصحيح يدوي، وصور في الأسئلة.
- محتوى مسجل (فيديو) بحماية ومتابعة مشاهدة.
- تقارير مقارنة بين الفروع لسلاسل السناتر.
- تصدير Excel وPDF للتقارير والكشوف.
